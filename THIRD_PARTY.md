# Third-party references / dependencies

## 3DS-Texture-Forge

Used as an external source dependency for decrypted Nintendo 3DS filesystem parsing and PICA200 pixel decoding. It is downloaded by `bootstrap_tools.py`; it is not bundled in this archive.

## UntoldUnpack — xdanieldzd

Public reverse-engineering reference for Etrian Odyssey Untold-series HPI/HPB archives and Atlus STEX behavior.

## Amicitia / AtlusLibSharp — Struggleton and contributors

Public reverse-engineering reference for the Atlus EPL general-resource-package layout. 0.11 implements a small independent, read-only Python parser for the documented EPL table/member structure; Amicitia binaries/source are not bundled.

## pmd_farc / pmd_sir0 — marius851000

Format reference for the optional PMD-style FARC/SIR0 fallback retained from earlier builds.
